Flash 0.2.104 improves the desktop experience around ekFlow, Library media, and controls.

- Keeps ekFlow in its own window so minimizing Flash does not hide it, and adds a close button to the ownership/access screen.
- Refreshes Library thumbnails from the current website catalog.
- Fixes the Library `INSTALL STATE` and `SORT` menus so they stay open while selecting an option.
- Includes the latest tested desktop source and the redesigned native portable installer.

Downloads:

- `FlashSetup-0.2.104-x64.exe` — standard Windows installer.
- `FlashPortableInstaller.exe` — lightweight portable installer (the supported portable build).
