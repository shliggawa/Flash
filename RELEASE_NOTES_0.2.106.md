# Flash 0.2.106

Flash 0.2.106 is the corrected follow-up to 0.2.105.

- Restores the packaged startup entrypoint required by the desktop runtime.
- Keeps the Library thumbnail cache refresh so current artwork is shown.
- Shows credit prices for paid items in Library Explore More instead of labeling them Free.
- Includes the supported native portable installer.

Downloads:

- `FlashSetup-0.2.106-x64.exe` - standard Windows installer.
- `FlashPortableInstaller.exe` - supported lightweight portable installer.
