Flash 0.2.103 is a substantial desktop update focused on installation, Library clarity, purchasing, and reliability.

- Makes managed Fuse detection and one-click installation more reliable, including custom Resolve paths and existing installations.
- Corrects Library ownership defaults: ekFlow 2 stays hidden until owned, while ekFlow 2 Free is enabled for new accounts.
- Improves the Library experience with clearer installed/missing states, install reminders, watched-path controls, and local file actions.
- Enables credit purchases from the Flash app through the linked-account Dodo Payments checkout flow.
- Improves Health diagnostics, repair behavior, wording, and Resolve process detection.
- Replaces the legacy ~95 MB Electron portable installer with the redesigned native 440 KB installer.

The old Electron portable installer is deprecated. New and existing users should use `FlashPortableInstaller.exe` from this release.
