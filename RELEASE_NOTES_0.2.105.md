# Flash 0.2.105

Flash 0.2.105 refreshes the desktop Library artwork and packages the latest tested desktop source.

- Uses a new Library catalog cache namespace so stale artwork from older installs is not reused.
- Keeps the ekFlow window independent when the main Flash window is minimized.
- Includes the current Library menu and thumbnail behavior fixes.
- Keeps the supported native portable installer as the lightweight update path.

Downloads:

- `FlashSetup-0.2.105-x64.exe` - standard Windows installer.
- `FlashPortableInstaller.exe` - supported lightweight portable installer.
